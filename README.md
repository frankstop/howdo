**Unified Master Specification Application**

Summary of Features & Updates:
Interactive Multi-Domain Explorer: Organized all 18 specification sections across the 4 core parts (Part 1: PRD, Part 2: SRS, Part 3: TDD, Part 4: Appendices) with detailed cards, inputs/outputs, and acceptance criteria.
Visual Engineering Dashboards: Embedded responsive Chart.js visualizations showing the structural breakdown across engineering domains and non-functional requirement (NFR) depth models.
Role-Based Filtering & Live Search: Enables Product Owners, Systems Engineers, Architects, and DevOps Leads to immediately isolate relevant sections.
Interactive Spec Studio & Markdown Generator: Allows users to dynamically select spec modules, audit coverage, inspect sample code snippets, and copy formatted Markdown templates directly to the clipboard.
